## 📌 Overview

This dashboard analyzes **Netflix content data** to uncover trends in genres, release patterns, and audience preferences.

It provides insights into **content distribution, popularity, and viewing trends**, helping understand what drives engagement.

---

## 🚀 Key Highlights

- 🎥 **Genre Distribution Analysis**
- 🌍 **Country-Wise Content Trends**
- ⭐ **Ratings & Popularity Insights**
- 📅 **Release Year Trend Analysis**
- 🎭 **Content Type Comparison (Movies vs TV Shows)**

---

## 📊 Dashboard Insights

- Certain genres dominate overall **content distribution and popularity**  
- Content production has increased significantly in **recent years**  
- Regional trends highlight differences in **viewer preferences**
