# Netflix Dashboard

## 📌 Overview
Analyzes Netflix content data including genres, ratings, and release trends.

## 🎯 Objectives
- Analyze content distribution
- Track genre popularity
- Study release trends

## 📊 Key Metrics
- Total Titles
- Genre Count
- Average Rating

## 📈 Visualizations
- Titles by Genre (Bar)
- Release Trend (Line)
- Ratings Distribution

## 💡 Insights
- Identifies trending genres
- Shows content growth over years

## 🛠 Tools Used
- Power BI
