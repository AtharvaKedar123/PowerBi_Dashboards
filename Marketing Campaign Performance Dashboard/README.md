# Marketing Campaign Performance Dashboard

## 📌 Overview
Evaluates campaign performance across channels.

## 🎯 Objectives
- Measure ROI
- Compare campaign performance
- Track conversions

## 📊 Key Metrics
- ROI
- Conversions
- Cost per Acquisition (CPA)
- Click-Through Rate (CTR)

## 📈 Visualizations
- Campaign ROI (Bar)
- Conversion Funnel
- Channel Performance

## 💡 Insights
- Identifies best-performing campaigns
- Optimizes marketing spend

## 🛠 Tools Used
- Power BI
- DAX
