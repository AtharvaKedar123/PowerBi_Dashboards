# Fraud Detection & Risk Monitoring Dashboard

## 📌 Overview
Detects fraudulent transactions and monitors risk patterns.

## 🎯 Objectives
- Identify fraud transactions
- Analyze fraud trends
- Detect high-risk regions

## 📊 Key Metrics
- Fraud Rate (%)
- Total Fraud Cases
- Transaction Volume
- Risk Score

## 📈 Visualizations
- Fraud vs Non-Fraud (Donut)
- Fraud Trend (Line)
- Fraud by Region (Map)
- Hour-wise Fraud Analysis

## 💡 Insights
- Detects fraud spikes
- Highlights suspicious patterns

## 🛠 Tools Used
- Power BI
- DAX
