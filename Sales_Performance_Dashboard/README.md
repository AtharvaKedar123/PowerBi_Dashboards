# Sales Performance Dashboard

## 📌 Overview
Analyzes sales performance across products, regions, and time.

## 🎯 Objectives
- Track revenue growth
- Analyze sales trends
- Identify top regions

## 📊 Key Metrics
- Total Sales
- Profit
- Orders

## 📈 Visualizations
- Sales Trend (Line)
- Region-wise Sales (Map)
- Product Performance (Bar)

## 💡 Insights
- Identifies high-performing regions
- Tracks seasonal trends

## 🛠 Tools Used
- Power BI
