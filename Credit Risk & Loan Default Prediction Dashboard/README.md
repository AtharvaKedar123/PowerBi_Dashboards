## 📌 Overview

This dashboard analyzes borrower behavior and financial indicators to identify **high-risk loan applicants** and predict potential defaults.

It provides a clear, data-driven view of **credit risk**, helping financial institutions make smarter lending decisions.

---

## 🚀 Key Highlights

- ⚠️ **Loan Default Risk Segmentation** (Low / Medium / High)
- 📊 **Credit Score vs Default Trend Analysis**
- 💰 **Income, Loan Amount & Debt Ratio Insights**
- 🔍 **High-Risk Customer Identification**
- 📉 **Default Patterns Across Demographics**

---

## 📊 Dashboard Insights

- Customers with **low credit scores and high debt ratios** show higher default probability  
- Certain income groups carry **disproportionate risk exposure**  
- Risk segmentation enables **targeted loan approval strategies**
