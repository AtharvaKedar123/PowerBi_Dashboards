# Finance Dashboard

## 📌 Overview
Tracks financial performance including revenue, expenses, and profitability.

## 🎯 Objectives
- Monitor income vs expenses
- Analyze profit trends
- Track financial KPIs

## 📊 Key Metrics
- Revenue
- Expenses
- Profit Margin
- Net Profit

## 📈 Visualizations
- Profit Trend Line
- Expense Breakdown (Donut)
- Revenue vs Expenses (Bar)

## 💡 Insights
- Identifies cost-heavy areas
- Tracks financial health

## 🛠 Tools Used
- Power BI
- DAX
