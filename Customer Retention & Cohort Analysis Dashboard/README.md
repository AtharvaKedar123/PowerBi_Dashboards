# Customer Retention & Cohort Analysis Dashboard

## 📌 Overview
This dashboard analyzes customer retention patterns and cohort behavior over time to understand user engagement and churn.

## 🎯 Objectives
- Track customer retention rate
- Analyze cohort-wise behavior
- Identify drop-off points

## 📊 Key Metrics
- Retention Rate (%)
- Cohort Size
- Customer Lifetime
- Repeat Purchase Rate

## 📈 Visualizations
- Cohort Heatmap
- Retention Trend Line
- Customer Segmentation
- Monthly Cohort Table

## 💡 Insights
- Identifies high-retention cohorts
- Highlights churn-heavy periods

## 🛠 Tools Used
- Power BI
- DAX
- Data Modeling
