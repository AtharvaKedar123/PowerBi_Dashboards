## 📌 Overview

This dashboard analyzes user retention patterns using **cohort-based analysis** to understand how customers behave over time.

It provides deep insights into **customer engagement, churn trends, and lifecycle behavior**, enabling businesses to improve retention strategies.

---

## 🚀 Key Highlights

- 📅 **Cohort-Based Retention Tracking**
- 🔄 **Customer Churn Analysis**
- 📊 **Monthly Active User Trends**
- 📉 **Drop-Off & Retention Curve Analysis**
- 👤 **User Lifecycle Behavior Insights**

---

## 📊 Dashboard Insights

- Most user drop-offs occur within the **initial engagement period**  
- Retained users show consistent activity across **multiple time cohorts**  
- Identifying churn patterns helps improve **user retention strategies**
