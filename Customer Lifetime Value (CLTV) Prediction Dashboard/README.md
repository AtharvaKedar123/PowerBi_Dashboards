## 📌 Overview

This dashboard analyzes customer purchasing behavior to estimate **Customer Lifetime Value (CLTV)** and identify high-value customer segments.

It provides a data-driven approach to understanding **long-term customer profitability**, enabling businesses to focus on retention and revenue growth.

---

## 🚀 Key Highlights

- 💎 **Customer Segmentation Based on CLTV**
- 📊 **CLTV Trend Analysis Over Time**
- 🔁 **Repeat Purchase Behavior Insights**
- 💰 **Revenue Contribution by Customer Segments**
- 📉 **High vs Low Value Customer Identification**

---

## 📊 Dashboard Insights

- A small segment of customers contributes to a **major portion of total revenue**  
- Repeat customers show significantly higher **lifetime value**  
- Identifying high-value users enables **targeted retention strategies**
